# PS2 vs PC comparisons

The comparison tooling (PCSX2 next to the PC game with the mods, for the
same scene: `tools/compare`, `tools/pcsx2ctl`, `tools/calllist`,
`tools/shotrun` and the replays) and its notes and numbers are in
FFX Demaster: [`docs/compare.md`](https://github.com/yutamago/ffx-demaster/blob/main/docs/compare.md)
there. The tools take the mods' `efl/x` folders (one `--mod` per folder).
The other documents name it as `docs/compare.md`.
