# The PS2 debugger

PCSX2 with a debug server (breakpoints, watchpoints, registers,
disassembly on the running PS2 game) and the `pcsx2` MCP server: set up
and described in FFX Demaster,
[`docs/dev/debugger.md`](https://github.com/yutamago/ffx-demaster/blob/main/docs/debugger.md),
next to the comparison tools that share its PCSX2.
